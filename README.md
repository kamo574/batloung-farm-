\# Batloung Farm Distribution System



Fruit distribution management system (Node.js, Express, MySQL).



\## Run locally

1\. Install Node.js and MySQL.

2\. Create the database `batloung\_farm`, then import it: `mysql -u root -p batloung\_farm < database.sql`

3\. Copy `.env.example` to `.env` and fill in your database details.

4\. `npm install`

5\. `npm start`

6\. Open http://localhost:3000



\## Features

Suppliers, fruits, vendors, purchases, sales, stock per packaging size, SQL reports, MySQL transactions (BEGIN, COMMIT, ROLLBACK), vendor payments and balances, receipts, route planner map.
